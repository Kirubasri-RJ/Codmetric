# Task 4 - Voice Assistant

A simple voice-controlled assistant built as part of the Codmetric Internship Program.

## Description
This project implements a basic voice assistant that listens to spoken commands, processes them, and responds either through speech or text. It can perform simple tasks such as answering questions, telling the time, or executing basic commands based on voice input.

## Features
- Voice recognition to capture and process spoken commands
- Text-to-speech responses
- Performs basic tasks (e.g., greetings, time, simple Q&A)
- Easy to extend with new voice commands

## Technologies Used
- Python
- SpeechRecognition library
- pyttsx3 (text-to-speech)

## How to Run
1. Clone this repository: git clone https://github.com/Kirubasri-RJ/Codmetric.git
2. Navigate to this folder: cd Codmetric/Task4-voice-assistant
3. Install required libraries: pip install speechrecognition pyttsx3 pyaudio
4. Run the assistant: python voice_assistant.py
5. Speak your command after the prompt

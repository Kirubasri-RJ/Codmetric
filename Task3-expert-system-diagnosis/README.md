# Task 3 - Expert System for Diagnosis

A rule-based expert system built as part of the Codmetric Internship Program, designed to simulate diagnostic decision-making.

## Description
This project implements an expert system that mimics the decision-making process of a human expert in a specific domain (such as medical or technical diagnosis). It uses a knowledge base of rules and facts, applying logical inference to arrive at a diagnosis or conclusion based on user-provided symptoms or inputs.

## Features
- Rule-based inference engine
- Takes user input (symptoms/conditions) and matches against a knowledge base
- Provides a diagnosis or recommendation based on matched rules
- Simple, interactive console-based interface

## Technologies Used
- Python

## How to Run
1. Open Google Colab.
2. Upload the Expert System file.
3. Run the code.
4. Answer the questions displayed on the screen.
5. View the diagnosis and suggested solution.

## How It Works
The system stores a set of rules (if-then logic) representing expert knowledge. When the user provides inputs, the system checks them against these rules to infer the most likely diagnosis or outcome.

## Future Improvements

- Add a confidence score for each diagnosis

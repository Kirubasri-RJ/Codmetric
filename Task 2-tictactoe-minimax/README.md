# Task 2 - Tic-Tac-Toe with Minimax Algorithm

A console-based Tic-Tac-Toe game built as part of the Codmetric Internship Program, featuring an AI opponent powered by the Minimax algorithm.

## Description
This project implements the classic Tic-Tac-Toe game where the computer plays optimally using the Minimax algorithm, a decision-making algorithm used in game theory. The AI evaluates all possible future moves to choose the best possible move, making it unbeatable.

## Features
- Two-player mode (Human vs Human) or Human vs AI
- AI opponent using the Minimax algorithm for optimal decision-making
- Simple console-based interface
- Detects win, loss, and draw conditions

## Technologies Used
- Python

## How to Run
1. Clone this repository: git clone https://github.com/Kirubasri-RJ/Codmetric.git
2. Navigate to this folder: cd Codmetric/Task2-tictactoe-minimax
3. Run the game: python tictactoe.py
4. Follow the on-screen prompts to play

## Algorithm Overview
The Minimax algorithm works by simulating all possible moves and their outcomes, then choosing the move that minimizes the opponent's best possible outcome while maximizing its own.
